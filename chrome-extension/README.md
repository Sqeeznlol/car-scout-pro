# Autosnipe Mobile.de Extension

## Installation

1. **Lade den `chrome-extension/` Ordner herunter** (z.B. als ZIP entpacken)
2. **Chrome öffnen** → Adresse: `chrome://extensions/`
3. **Entwicklermodus aktivieren** (Toggle oben rechts)
4. **"Entpackte Erweiterung laden"** klicken
5. **Ordner `chrome-extension/`** auswählen
6. Fertig — Extension ist installiert ✓

## Nutzung

- Öffne ein mobile.de Inserat (z.B. https://suchen.mobile.de/fahrzeuge/details.html?id=...)
- Die Extension extrahiert automatisch alle Daten und sendet sie an Autosnipe
- Du siehst unten rechts ein grünes Banner mit Marge + Deal Score
- Falls Daten falsch sind: Klick "🔄 Autosnipe Re-Sync" Button unten links

## Was wird erfasst

- Preis (Brutto + Netto)
- MwSt-Status (ausweisbar/§25a)
- Standort (PLZ + Stadt)
- Land
- Eckdaten (km, EZ, Leistung, Kraftstoff, Getriebe)
- Verbrauch, CO2, Emissionsklasse
- Händler (Name, Telefon, Adresse, Website)
- Alle Bilder
- Komplette Ausstattung
- Beschreibung
- Halter, HU, Farbe, Karosserie, Türen, Sitze
